# Сторонние компоненты

Собственный код BardForge распространяется по [MIT](LICENSE). Зависимости сохраняют свои лицензии и уведомления; [границы лицензирования](LICENSING.md) описаны отдельно.

## Прямые зависимости

| Компонент          | Закреплённая версия       | Лицензия   | Использование                                       |
| ------------------ | ------------------------- | ---------- | --------------------------------------------------- |
| `ws`               | 8.22.1 в lock-файле relay | MIT        | WebSocket-сервер, отдельная установка relay         |
| `@playwright/test` | 1.64.1                    | Apache-2.0 | Только автоматические проверки                      |
| `eslint`           | 10.14.0                   | MIT        | Только проверка JavaScript                          |
| `@eslint/js`       | 10.0.1                    | MIT        | Рекомендованные правила ESLint                      |
| `globals`          | 17.0.0                    | MIT        | Описание глобальных имён Node и браузера для ESLint |
| `prettier`         | 3.9.10                    | MIT        | Только форматирование исходников                    |

Точные версии, целостность загрузок и декларации лицензий транзитивных пакетов сохранены в `package-lock.json` и `services/relay/package-lock.json`. При установке npm сохраняет лицензионные файлы зависимостей в `node_modules`. Их нельзя удалять из распространяемой установки relay.

Для цепочки инструментов ESLint закреплён транзитивный `minimatch` 11.0.3 (BlueOak-1.0.0), как в исходном проекте. Это устраняет известную проблему предыдущей версии без отключения проверки `npm audit`; совместимость проверяется запуском ESLint на содержимом репозитория.

Playwright устанавливает отдельную сборку Chromium для тестов. У неё есть собственные лицензии и уведомления сторонних компонентов; Chromium не входит в ZIP приёмника. Playwright и `playwright-core` используют Apache-2.0.

В ZIP приёмника нет npm-зависимостей, сторонних аудиофайлов, шрифтов, изображений и браузерных бинарников. Код использует встроенные WebRTC/Web Audio API и API хоста Foundry. Foundry VTT приобретается и устанавливается отдельно; его программные файлы здесь не распространяются. Тестовый звук синтезируется алгоритмически.

Это перечень технических деклараций зависимостей, а не утверждение о завершённом юридическом аудите всех будущих вариантов распространения.

Перед принятием MIT проверены 84 декларации лицензий в основном lock-файле и одна в relay: отсутствующих деклараций нет. Собственный транспортный код выделен из Studio (исходный commit указан в README), сторонних copyright-заголовков в нём не обнаружено. Такая проверка не гарантирует отсутствие неизвестных прав третьих лиц. ZIP сохраняет LICENSE BardForge, границы лицензии и этот перечень; он не включает лицензируемый отдельно код Foundry VTT.
